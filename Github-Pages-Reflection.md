# Reflection on Using GitHub Pages

## STAR Method

### Situation

The final stage of my digital portfolio project required me to publish my portfolio online using GitHub Pages. Before this assessment, I had primarily used GitHub for version control and storing programming projects, but I had little experience deploying a website directly from a GitHub repository.

### Task

My objective was to transform my GitHub repository into a publicly accessible portfolio that showcased my CV, work readiness evidence, reflections, and technical skills in a professional and organised manner. I also wanted to gain practical experience with website deployment and understand how developers use GitHub Pages to present their work.

### Action

I organised my repository using a clear folder structure and created all portfolio content using Markdown. After completing the portfolio, I enabled GitHub Pages through the repository settings and configured it to publish my website from the main branch. Once the site was deployed, I tested each page and navigation link to ensure everything displayed correctly and made any necessary adjustments to improve the overall presentation and user experience.

### Result

Successfully publishing my portfolio demonstrated that GitHub can be used for much more than source code management. I developed practical skills in website deployment, version control, documentation, and maintaining a professional online presence. The project also reinforced the importance of presenting technical work in a clear and organised way. I now have a professional portfolio that I can continue updating with future projects, certifications, and achievements as I progress in my software development career.
